# NoHoldr (Previously AIContentSuite)

Fast file tools that run locally in your browser.

## Features

**PDF Tools**
- Merge, Split, Academic Split
- Compress, Rotate, Crop
- Convert to/from images, Word, Excel

**Image Tools**
- Compress, Resize, Convert
- Crop, Rotate, Blur
- EXIF metadata management

**Coming Soon**
- Media tools (audio/video)
- File utilities (ZIP, rename)
- Data tools (CSV, JSON, hash)
- AI features (opt-in, your API key)

## Privacy

- Files processed **in browser memory**
- **Never uploaded** to any server
- **Never stored** anywhere
- **No tracking**, no accounts

## Run Locally

```bash
npm install
npm run dev
```

## Tech Stack

- Next.js 16.1.1 (Turbopack)
- TypeScript
- Tailwind CSS v4
- shadcn/ui
- pdf-lib
- Canvas API
