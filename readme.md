# NoHoldr

> *No holding files. No hidden processing. No retention.*

**Privacy-focused file tools that run entirely in your browser.**

[![License: NAL-2.0](https://img.shields.io/badge/License-NAL--2.0-blue.svg)](LICENSE)
[![Made by Deviantkay](https://img.shields.io/badge/Made%20by-Deviantkay-purple.svg)](https://github.com/Deviantkay)

---

## Features

| Category | Tools |
|----------|-------|
| **PDF** | Merge, Split, Academic Split, Compress, Rotate, Crop, Convert (Image/Word/Excel) |
| **Image** | Compress, Resize, Convert, Crop, Rotate, Blur, EXIF Editor |
| **Media** | Audio/Video tools |
| **Files** | ZIP, Batch Rename |
| **Data** | CSV, JSON, Hash tools|
| **AI** | Opt-in features with your API key |

---

## Privacy Promise

| Guarantee | Description |
|-----------|-------------|
| 🔒 **In-Browser** | Files processed entirely in browser memory |
| 🚫 **No Upload** | Never sent to any server |
| 🗑️ **No Storage** | Never saved anywhere |
| 👤 **No Tracking** | No accounts, no analytics |

---

## Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev
```

## Tech Stack

| Layer | Technology |
|-------|------------|
| **Framework** | Next.js 16.1.1 (Turbopack) |
| **Language** | TypeScript |
| **Styling** | Tailwind CSS v4 |
| **Components** | shadcn/ui |
| **PDF Engine** | pdf-lib, PDF.js |
| **Image** | Canvas API, Piexifjs |
